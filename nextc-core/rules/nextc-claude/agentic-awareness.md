# Skill Selection

Before working on a request, check the available skills and use the one that matches the task.

- Scan the skills list against the request; when one fits, invoke it with the Skill tool before doing the work yourself, because the skill encodes a tested procedure.
- When several fit, invoke them in a logical order (for example planning before review).
- Do not re-invoke a skill that is already running or was just invoked this turn.
